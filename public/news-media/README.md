Carpeta donde el editor de Novedades (`/cms`) guarda las fotos que se adjuntan a
las notas. Cada archivo queda accesible en `/news-media/<archivo>`, que es lo que
se guarda en el campo `image` del frontmatter de cada nota.

No hay que subir nada acá a mano: se sube solo al adjuntar una foto en el editor.
